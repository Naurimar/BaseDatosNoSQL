# Bases de Datos NoSQL — Semana 1

Guía de aprendizaje: Diagnóstico y fundamentos de bases de datos NoSQL.

Programa: Tecnología en Análisis y Desarrollo de Software — ADSO.
Caso: Unidad de Emprendimiento del SENA (simulación didáctica).

## Estructura
- `diagnostico/`: diagnóstico individual, teoría, autoevaluación y P1–P3.
- `docs/`: documentación y diagnostico.
- `scripts/`: script de exploración MongoDB.
- `evidencias/`: capturas y resultados reales que debe agregar el aprendiz.

## Importante
Los datos del caso son ficticios. No guardar contraseñas, tokens, documentos de identidad ni información real.
Las versiones del entorno y los resultados de conexión deben completarse con datos reales del computador del aprendiz.
